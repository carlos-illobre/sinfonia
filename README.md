# Sinfonia

Una aplicación web para crear melodías y canciones: escribirlas, escucharlas, elegir
instrumentos y sumarles efectos. Tiene dos vistas de la misma canción: la **vista simple**, para
quien no sabe nada de teoría musical, con un idioma propio sin notas, acordes ni pentagramas; y
la **vista de teoría**, para quien sabe.

**La documentación manda; el código es secundario.** Todo lo que hace falta para entender y
reconstruir la aplicación está en [`docs/`](docs/).
